# Modèle de données initial

## Entités communes

### Personne signataire

- genre
- civilité
- prénom
- nom
- adresse personnelle
- date de naissance
- nationalité
- filiation
- fonction dirigeant

### Société

- forme sociale
- dénomination
- capital
- siège social

### Signature

- lieu
- date
- image optionnelle

### Domiciliation

- adresse affichée des locaux

## Principe

Les informations n'ont pas toutes vocation à devenir des variables globales.
Si une information n'apparaît qu'une seule fois, elle peut rester un champ manuel contrôlé.
