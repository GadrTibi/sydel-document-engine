- **2 modèles réellement spécifiques SCI** : `Modèle statuts SCI.docx` et `Modèle statuts SCI IRIS.docx`.
- **5 modèles « génériques »** présents dans le dossier Drive « Création SCI » mais qui sont en réalité
  des documents **transverses** (3 docs « tous les cas » + PV nomination gérant + lettre option IS) :

  réellement supporté (et au-delà de 3 ?) est une **question métier ouverte** (cf. `NOTEBOOKLM_PROMPTS.md`).

  associée + démembrement » ? → **à confirmer** (NotebookLM/Rafael).
