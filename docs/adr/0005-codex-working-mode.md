# ADR-0005 — Mode opératoire GitHub + Codex

- Statut : PROPOSÉ
- Date : 2026-05-12

## Proposition

Utiliser Codex comme accélérateur de build logiciel, mais dans un cadre repo-first :

- `AGENTS.md` à la racine ;
- PR petites ;
- revues humaines ;
- tickets traçables ;
- activation progressive des automatisations.

## Raison

Le volume documentaire impose une rigueur forte, de la répétabilité et un cadre explicite pour les agents de code.
