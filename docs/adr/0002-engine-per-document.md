# ADR-0002 — Moteur construit par document canonique

- Statut : ACCEPTÉ
- Date : 2026-05-12

## Décision

Le moteur n'est pas construit par feuille d'arbre ou par cas, mais par document canonique.

## Conséquence

Chaque document cible dispose d'un générateur dédié avec condition générale et, si nécessaire, conditions spécifiques.
